### #1 — `coa_applications` GIST spatial index missing (MUST-FIX gate)
**Severity:** HIGH | **Filed:** 2026-05-20 (12 days) | **Planned home:** WF2 + migration before CoA killswitch flip

`src/features/leads/lib/get-lead-feed.ts` live-verify EXPLAIN ANALYZE on `lead_type=all` shows **Parallel Seq Scan on coa_applications** (4.4s). No GIST index on `(latitude, longitude)`. The CoA UNION arm in the mobile lead feed is currently behind `LEAD_FEED_DISABLE_COA=1` (default ON). **This index is the explicit gate condition** before that killswitch can be turned off in production. `get-lead-feed.ts` was modified in the most recent commit (`1e6e5d9`). Unblocks the entire CoA mobile feed activation milestone.

_Fix:_ `CREATE INDEX CONCURRENTLY idx_coa_applications_location_gist ON coa_applications USING GIST (ST_MakePoint(longitude, latitude)::geography) WHERE latitude IS NOT NULL AND longitude IS NOT NULL;` (new migration). See `docs/reports/review_followups.md` item #119.

### #3 — `cost-model-shared.js` falsy-0 triple (three HIGHs → MED, one WF3 sweep)
**Severity:** 3× MED (decayed from HIGH after 24 days) | **Filed:** WF2 #3 2026-05-08 | **Planned home:** WF3 bundle

Three `||` where `??` is required, all in `src/features/leads/lib/cost-model-shared.js`:
- **l.193** `computeGfa`: `row.storeys || 1` inflates GFA for valid 0-storey permits.
- **l.234** `computeEffectiveArea`: `pct !== undefined && pct > 0` causes pct=0 rows (valid "no-construction-area" config) to fall through to 1.0 full-GFA default.
- **l.293** `computeTradeValue`: `rateRow.structure_complexity_factor || 1.0` overrides operator-set 0 complexity.

All three fix to `??`; one commit, three bug closures. Root cause documented in original WF2 #3 review.

### #4 — `compute-cost-estimates.js` scopeMatrix `.trim()` missing (1-line HIGH→MED)
**Severity:** MED (decayed from HIGH after 24 days) | **Filed:** WF3 2026-05-08 | **Planned home:** WF3 or bundle with #3

`scripts/compute-cost-estimates.js:241-242` builds `scopeMatrix` key as `` `${r.permit_type.toLowerCase()}::${r.structure_type.toLowerCase()}` `` — **no `.trim()`**. Spec 83 §3 explicitly mandates `.toLowerCase().trim()`. A trailing whitespace in any `scope_intensity_matrix` DB row silently causes full-GFA fallback, which is the very inflation pattern WF2 #3 gated. Low blast radius (1 line), high correctness value. Bundle with #3 sweep to close both in one WF3.

### #5 — `get-lead-feed.ts` wsib INNER-JOIN regression (MED, 30-50% builder-lead drop)
**Severity:** MED (decayed from HIGH after 24 days) | **Filed:** WF3 2026-05-08 | **Planned home:** WF3

`src/features/leads/lib/get-lead-feed.ts:478` has `AND w.business_size IS NOT NULL` on a `LEFT JOIN wsib_per_entity`. This converts the LEFT JOIN to an implicit INNER JOIN, silently dropping any builder lead where `wsib_per_entity.business_size IS NULL` (new contractors, GTA-condition failures). Estimated 30-50% of builder leads affected. The mobile feed is `get-lead-feed.ts`'s primary consumer and this file was touched in the most recent commit. Fix: remove the `WHERE` predicate; UI handles NULL `business_size`.
