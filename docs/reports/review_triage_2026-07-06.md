### #2 — `get-lead-feed.ts` wsib LEFT JOIN silently acting as INNER JOIN (HIGH)
**Source:** DeepSeek WF3 (2026-05-08). **Planned home:** WF3.

Confirmed still in `src/features/leads/lib/get-lead-feed.ts`:
- **Line 441**: `LEFT JOIN wsib_per_entity w ON w.linked_entity_id = e.id`
- **Line 478**: `AND w.business_size IS NOT NULL` — converts the LEFT JOIN to an effective INNER JOIN.

Consequence: new contractors and GTA-condition-failure entities with no WSIB record are silently dropped from builder candidates. Reviewer estimated 30–50% of builder leads affected. This file was last touched 2026-05-20 (commit `1e6e5d9`).

**Fix:** Remove `AND w.business_size IS NOT NULL` from the WHERE clause; let the UI handle NULL `business_size`. Verify against Spec 91 §4.3 builder-display contract (~1-line SQL change).

**Rationale for #2:** Silently drops up to half the builder lead pool. Directly affects product core value proposition with no client-visible error.
