## Scenario scores — whole scorable corpus (P14-C)

- **recall** = |attached ∩ inspected| / |inspected| (the trades that PROVABLY showed up — did we attach them).
- **conf** = |attached ∩ inspected| / |attached| (lower bound; dragged down by un-inspectable finishing trades — NOT true precision).
- **prec(insp)** = precision restricted to the inspectable trade universe = |(attached∩INSPECTABLE) ∩ inspected| / |attached∩INSPECTABLE| (the fair precision proxy).
- **mean attached** = mean active/attached trades per permit (inflation signal).
