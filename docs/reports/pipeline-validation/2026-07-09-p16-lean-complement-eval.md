## Scenario scores — whole scorable corpus (P14-C)

- **recall** = |attached ∩ inspected| / |inspected| (the trades that PROVABLY showed up — did we attach them).
- **conf** = |attached ∩ inspected| / |attached| (lower bound; dragged down by un-inspectable finishing trades — NOT true precision).

## D8 obligations + calibration provenance

- **Calibration method (D3):** the complement was calibrated by a whole-corpus per-inspectable-trade
  TP/FP diagnostic (framing 40 TP/58%, insulation 42/55%, excavation 15/52%, concrete 7/37% KEPT;
  hvac 0/69, plumbing 0/38, demolition 0/61, drain-plumbing 3/48, site-preparation 2/36, shoring 0/1
  DROPPED as pure false-positive inference adds). The DROP signal is structural (0% precision), not
  split noise, so it holds identically on DEV; the GATE is scored on the held-out half regardless.
- **Fire Separations → fire-protection ambiguity [D8b]:** 48 corpus rows map `Fire Separations` to
  `fire-protection` though the stage is a rated drywall/framing assembly. Symmetric (it inflates both
  attached-and-truth), non-fatal; the complement does NOT add fire-protection, so this does not affect
  the gate. Documented; do not "fix" the mapping without deep_scrapes data.
- **PLB 45% evidence-recall gap [D8c]:** root-caused in the 16A notes
  (`2026-07-10-p16-16a-notes.md`) — a ground-truth/taxonomy artifact (a Plumbing(PS) permit's DWV +
  Fire-Service inspections split one plumber's scope across plumbing/drain-plumbing/fire-protection).
  The inference layer never touches narrow-scope permits, so this is an evidence-layer floor, not
  closable by P16.
- **temporary-fencing [D8d]:** deprecated-for-emission (Spec 80 §5.B.2); kept OUT of every complement
  (`COMPLEMENT_EXCLUDED_SLUGS`) and OUT of the starvation counter.
- **deep_scrapes-resume re-measure [D8a] — STANDING OBLIGATION:** the corpus is 122 permits (partial).
  Re-run this harness when deep_scrapes resumes for FINAL calibration. The GO is PROVISIONAL; the
  `p16_inference_layer_enabled` logic var makes the layer flip-off-able if the re-measure regresses.
