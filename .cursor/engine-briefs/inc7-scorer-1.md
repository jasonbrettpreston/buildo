## The API the tests lock (all exports of the .mjs; pure unless stated)
- `requiredCorrect(n, pct, rounding)`: ceil|floor|round of n*pct/100 (floating-safe: round to 9 dp before ceil/floor). (25,90,'ceil')=23; (25,90,'floor')=22; (25,90,'round')=23 (22.5 rounds up); (10,90,'ceil')=9; (20,90,'ceil')=18 (18.000000000000004 must not become 19). Unknown rounding throws an Error whose message starts `inc7_settings_invalid`.
- `validateSettings(s)`: string[] of violation codes, [] for the shipped file. Codes: `gate_measure_unknown:<m>` (gate measure not in direction.measures), `rounding_unknown:<r>`, `spread_unknown:<x>` (allowed iqr|min_max|stdev), `denominator_unknown:<x>` (allowed all_cases|evaluated_cases), `class_rule_class_empty`, `threshold_kind_unknown:<id>` (allowed pct_min|count_max), `field_missing:<m>` (a direction measure without layer3.field_by_measure entry).
- `maxFor(layer3Rows, parcelId, buildingType, measure, settings)` -> `{value:number|null, reason:'ok'|'no_class'|'no_row'|'status:<status>'}`. Rows are `{parcel_id, building_type, field_id, status, value}`; the field comes from `settings.layer3.field_by_measure[measure]`; usable only when status is in `settings.layer3.usable_status` (shipped: `computed`); buildingType null/undefined -> reason `no_class`; no row for that parcel+class+field -> `no_row`; a row with status `not_evaluated` -> `status:not_evaluated`; value stored as a numeric string is returned as a Number.
- `directionCase({applicant, max, variance, tol})` -> `{status}`: applicant null/undefined -> `no_applicant_figure`; max null -> `not_evaluated`; variance false -> `correct` when applicant <= max+tol else `wrong`; variance true -> `correct` when applicant > max+tol else `wrong`. (tol boundary: applicant == max+tol with variance false is correct; with variance true is wrong.)
- `scoreDirection(cases, layer3Rows, varianceRows, settings)` -> `{<measure>: {gated, cases, evaluated, correct, wrong, not_evaluated, no_applicant_figure, denominator, required, pass, wrong_cases:string[], not_evaluated_cases:string[]}}` for each measure in `direction.measures`. Case shape `{case, parcel_id, applicant_class, new_build, applicant:{gfa,height,storeys,footprint,units}}`. A "variance on the measure" = a variance row with `city_row:true`, same `case`, same `measure`, `granted` in `direction.variance_granted_values` (shipped yes|modified; `no` is not a variance). `denominator`: with `direction.denominator` = `all_cases` it is the number of cases WITH an applicant figure for that measure (not-evaluated cases count in it and are not correct); with `evaluated_cases` it is `evaluated`. `required = requiredCorrect(denominator, threshold_pct, count_rounding)`. `pass = correct >= required` and denominator > 0. `gated` = measure is in `gate_measures`.
- `scoreCloseness(cases, layer3Rows, varianceRows, settings)` -> `{measure:'gfa', n, median, spread, values:[{case, ratio}], threshold:null, threshold_met:null}`. Population per `closeness.population`: `new_build` true cases with no granted variance on the closeness measure, an applicant figure and a usable max > 0. ratio = applicant/max rounded to 3 dp. median = ordinary median (even n averages the two middle values, rounded to 3 dp). spread: for `iqr` `{kind:'iqr', q1, q3, iqr}` using linear interpolation between ranks (R type 7), 3 dp; for `min_max` `{kind:'min_max', min, max}`; for `stdev` `{kind:'stdev', stdev}` (population). n=0 -> median null and spread null. threshold stays what the settings hold (null -> `threshold_met` null; a number t -> `threshold_met` = median >= t).
- `classifyRow(facts, settings)` -> class string. facts `{city_row:boolean, our_verdict:string, limit_match:boolean|null}`. The first rule of `catch.class_rules` whose `city_row` equals, whose `our_verdict` list includes the verdict and (when the rule has `limit_match`) whose `limit_match` equals the fact; none -> `catch.unclassified_class`. With the shipped table: (true,EXCEEDS,true)=CAUGHT; (true,EXCEEDS,false)=WRONG LIMIT; (true,EXCEEDS,null)=NOT SCORED; (true,MAY EXCEED,*)=CAUGHT-ESTIMATE; (true,COMPLIES,*)=MISSED; (true,NOT EVALUATED,*)=MISSED; (false,EXCEEDS,*)=FALSE ALARM; (false,MAY EXCEED,*)=SOFT ALARM; (false,COMPLIES,*)=NOT SCORED.
- `limitMatch(cityLimit, ourLimit, settings)` -> true|false|null: null when either is not a finite number; else |a-b| <= max(catch.limit_match.abs, catch.limit_match.rel_pct/100*|cityLimit|).
- `scoreCatch(cases, layer3Rows, varianceRows, settings)` -> `{rows:[{case, measure, city_row, our_verdict, city_limit, our_limit, limit_match, category, class}], counts:{<class>:n}, denominator, rates:{<id>:...}, thresholds:[{id, kind, value, actual, pass}], pass}`. Variance row shapes: City row `{case, measure, city_row:true, granted, city_limit?, applicant_figure?, our_verdict?, our_limit?}`; our alarm with no City row `{case, measure, city_row:false, our_verdict, category?}`. When a City row has no `our_verdict`, derive it from the case's Layer 3 max of the measure (measure in `direction.measures`): max unavailable -> `NOT EVALUATED`, our_limit null; else figure = row.applicant_figure ?? case.applicant[measure]; figure > max+tolerance[measure] -> `EXCEEDS` else `COMPLIES`; our_limit = max. A given `our_verdict`/`our_limit` on the row wins over the derivation. `category` defaults to `other` and must be one of `catch.false_alarm_categories` for a FALSE ALARM else the row's category becomes `other`. `denominator` = count of rows whose class is in `denominator_classes` (NOT SCORED rows are excluded). A threshold of kind `pct_min`: actual = sum of counts of its classes / denominator * 100 (null when denominator is 0, pass false), pass when actual >= value (exact, not rounded). `count_max`: actual = sum of counts of its classes (when it names a `category`, only rows with that category), pass when actual <= value. `pass` = every threshold passes.
- `scoreInc7({cases, layer3Rows, varianceRows, settings})` -> `{direction, closeness, catch, ok, settings_digest}`; `ok` = every GATED direction measure passes and catch.pass. `settings_digest` = a 12-hex-char sha256 prefix of the canonical JSON of settings (keys sorted). Throws an Error starting `inc7_settings_invalid` when validateSettings is non-empty; throws `inc7_input_invalid:cases_duplicate:<id>` on a duplicate case id; `inc7_input_invalid:cases` when cases is not an array; `inc7_input_invalid:variance_rows` when varianceRows is not an array; `inc7_input_invalid:layer3_rows` when layer3Rows is not an array. Must not mutate any input (deep-freeze inputs in a test) and return deep-equal results on two runs (idempotency).
- `runInc7({reader, readJson, paths})` async: `readJson(p)` returns parsed JSON; `paths = {cases, variance_rows, settings}`; `reader.layer3Rows(parcelIds)` async returns the rows for exactly the distinct non-null parcel ids of the cases (sorted). Then returns `scoreInc7(...)`. A reader that rejects propagates the rejection; the reader is called once.
