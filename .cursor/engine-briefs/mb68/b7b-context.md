## Contract: `buildContext(parsed, deps = {})` async -> the `ctx` for `evaluateGate`
`parsed` = what `parseArgs` returns (`root`, `mode`, `base`, `target`). `deps` = `{ git, computeRun, readRegisterText }` all injectable for tests.
1. **Revisions.** commit: files come from the index (`rev = ':index'`), `base = 'HEAD'`, `nameStatus = git.stagedNameStatus(root)`, `commits = [nameStatus]`. push and ci: `base = parsed.base || git.mergeBase(root, parsed.target || '@{upstream}')` (nothing resolvable throws `Error('base_not_resolvable')`, which means exit 2), `rev = 'HEAD'`, `nameStatus = git.rangeNameStatus(root, base, 'HEAD')`, `commits = git.perCommitNameStatus(root, base, 'HEAD')`.
2. **Policy and classes.** layer23 from the BASE copy of `mcbylaws/protected-paths.json` (`git.readAt(root, base, ...)`, JSON, `layer23` array of strings), else `DEFAULT_LAYER23`; `classify = makeClassifier(layer23)`; `incrementIds = loadIncrements(root)`.
3. **Register.** `registerText` = the two register files via `readSpec69Rulings(root)` of `scripts/analysis/bylaw/universe.mjs` (dynamic import by file URL); `rulings = parseRulings(registerText)`; `cardExists = () => false`.
4. **Records.** list record paths at `rev` (commit: `git ls-files` via `git.git(root, ['ls-files', '--', 'docs/reports/loop-records'])`; push/ci: `git ls-tree -r --name-only HEAD -- docs/reports/loop-records`) matching `RECORD_RE`; parse each with `readAt`. `newRecords` = the ones whose path is an `A` entry of `nameStatus`. Current increment = the increment of the last `newRecords` item (sorted by increment then round), else of the highest round overall; `latest` = `{path, rec}` of that increment's highest round, or null; `firstRoundOfIncrement` = no record of that increment exists at `base`; `greenHistory` = distinct increments of records with `decision === 'accept'` that exist at `base` (an accepted record can only have landed through a green gate: say so in a comment); `prevCases` = case id -> `{status, got_sha}` of the previous round's record of that increment, or `{}`.
5. **Prereg.** the prereg for the round = the `scripts/analysis/bylaw-validation/coa-expected/prereg-MB-*-*.json` file at `rev` (list with the same ls) whose parsed `increment` equals `latest.rec.increment` and `round` equals `latest.rec.round`; `prereg` = parsed or null; `preregFile` = its path or null; `preregHistory` = `gitPreregHistory(root, preregFile, latest.path)` for push and ci, null at commit. `rowsTouched` = `prereg.rows_touched || []`; `newCases` = for every group present in `regression.cur` but not in `regression.base`, or ids added to a group, `{id, introduced_in: group.introduced_in}`.
6. **Bound set.** `changedBound = boundPaths(paths of nameStatus, classify)`; `treeBlobs = git.blobIdsAt(root, rev, [...changedBound, ...Object.keys(latest.rec.inputs)])`.
7. **Regression and floors.** `regression = { base, cur }`: `loadRegression(root, readText)` with `readText = (p) => git.readAt(root, <rev>, path.relative(root, p))` (throwing `data_missing` when null); base uses `base`, cur uses `rev`; a missing base file gives `base: null`; a missing cur file throws `data_missing`. `floors`: percent floors file(s) named by the groups' `producer.floors` (first group with one): `percentBase` / `percentCur` parsed from base / rev (null if absent); `countBase` / `countCur` from `mcbylaws/loop/floors-*.json` (first match, else null). `baselineOwed` = `cur` count-floors file's `owed_baseline` object if present else `{}`.
8. **Run.** `run = deps.computeRun({ root, regression: regression.cur, mode, registerText })` (default from `loop-gate-run.mjs`, lazy import); at ci the result may be null; set `run.baseRows` to null.
Return the ctx object with exactly the field names `evaluateGate` reads.
