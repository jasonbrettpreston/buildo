## Contract
- `expandHome(p)`.
- `casesFromRows(group, rows)` -> `[{ group, id: "<notice>|<n>", status: row.class, value: row.ours && row.ours.value, reason: row.ours && row.ours.reason, clause: row.clause_norm, got_sha: gotSha(row.ours-like {status: row.ours.status, value, reason}) }]` (`gotSha` from loop-record, applied to `{ status: row.class, value, reason }` so the hash covers the printed class and value). Also keep the original scorer row's `class` as `status`.
- `runProducer(root, group, deps = {})`: `kind` other than `coa-scorecard` throws `unknown_producer`. Spawns (`deps.spawn` defaults to `execFileSync`) `node <root>/scripts/analysis/bylaw-validation/coa-scorecard.mjs --root <root> --notices <data_dir>/<notices> --parcels <data_dir>/<parcels> --plan-facts <data_dir>/<plan_facts> --out <tmp>/sc.json` with a temp dir from `fs.mkdtempSync(os.tmpdir())` (removed afterwards), env copy without `GIT_*`, maxBuffer 64 MB, then reads the `rows`. Returns `{ rows, cases: casesFromRows(group.id, rows), scorecard }`. A non-zero exit throws.
- `pinMismatch(group, rows, root)` -> `['generated_not_regenerable']` when the `pin` file's `totals` differ from the class totals of `rows` (or `variances` differs from `rows.length`), else `[]`. A group without `pin` -> `[]`.
- `computeRun({ root, regression, mode, registerText, deps })`: groups to run: commit -> `fast === true`; push -> all; ci -> `external !== true`. For each: `runProducer`; floors via `checkPercentFloors(<read group.producer.floors>, rows, registerText)` (loop-floors); `pinMismatch`; collects cases (with `group`), `counts` = `{ "<group> cases": n }`, `baseRows` = null, `curRows` = `[{ group, id, status, clause }]`. Canary via `runCanary` (loop-decide) over `cases.map(c => ({ id: c.id, expected: c.value, got: c.value }))` with `compare = (a, b) => (canon(a) === canon(b) ? 'pass' : 'fail')`. Returns the `run` object evaluateGate expects: `{ cases, skipped: 0, canary, report: { violations, owed }, counts, baseRows, curRows, regenMismatch, groups: regression.groups.map(g => ({ id: g.id, introduced_in: g.introduced_in })), floorsOk: violations.length === 0 }`, or `null` when no group runs (ci with only external groups). Cases whose group was not run are not in `cases` (the CI note says so).
- `baseRowsFor(root, rev, regression, deps)`: NOT required.
