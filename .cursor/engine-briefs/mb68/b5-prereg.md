## Contract
- `preregPath(task, round)` -> `scripts/analysis/bylaw-validation/coa-expected/prereg-<task>-<round>.json`.
- `checkPreregFile(pre)` -> `prereg_shape:<message>` for each message of `checkPreregShape(pre)`; plus `prereg_task_missing` when `pre.task` is not a string `MB-<digits>`.
- `toScorerRows(rows)`: `rows` = `[{ group, id, status, clause }]` (id = `<notice>|<n>`, split at the LAST `|`, n numeric when numeric) -> `[{ notice, n, class: status, clause_norm: clause, clause }]`.
- `checkPreregMoves(pre, baseRows, curRows)` (gate-form rows): moves = `diffMoves(toScorerRows(baseRows), toScorerRows(curRows))`; totals = count by status of `curRows`; run `checkPrereg(pre, moves, totals)`; return `unexpected_move:<notice>#<n> <from>-><to>`, `missing_move:<clause>`, `totals_diff:<text>` (the result's `unexpected`, `missing`, `totals_diff`). `baseRows` null -> moves not checked (pass `null` to checkPrereg).
- `preregRefusesAccept(verdictViolations, decision)` -> `['accept_with_prereg_finding']` when `decision === 'accept'` and `verdictViolations.length > 0`.
- `checkPreregHistory({ preregCommits, roundCommit, isStrictAncestor, preregFile })`: `preregCommits` = commits (oldest first) that touched the prereg path, each `{ sha, files: string[] }`; `roundCommit` = `{ sha }` of the commit that ADDED the round record, or null; `isStrictAncestor(a, b)` a function. Codes: no round commit -> `[]` (nothing to order yet); none touching -> `prereg_missing`; more than one -> `prereg_edited_after_first_commit`; first prereg commit not a strict ancestor of the round commit -> `prereg_not_strictly_before_round`; first prereg commit's `files` not exactly `[preregFile]` -> `prereg_commit_not_alone`.
- `gitPreregHistory(root, preregFile, recordFile)` -> the argument for `checkPreregHistory`, using `git log --diff-filter=A --format=%H -- <record>` (last line = first add), `git log --reverse --format=%H -- <prereg>`, `git show --name-only --format= <sha>`, `git merge-base --is-ancestor`. Runs git with `execFileSync('git', ['-C', root, ...])` and an env copy WITHOUT any `GIT_*` variable (a hook's GIT_DIR would otherwise make `git -C <tmp>` write into the calling repository; see `src/tests/bylaw-use-scope-prereg.infra.test.ts`). Reading `process.env` only to build that scrubbed copy is the single permitted use.
