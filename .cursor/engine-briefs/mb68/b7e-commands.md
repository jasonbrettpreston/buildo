## Contract (every command takes an injectable `deps` as a third argument: `{ git, computeRun, now }`, defaults lazy-imported)
- `runCommand(parsed, write, deps)`: REFUSES (returns `{ violations: ['run_needs_mode_push_or_full'] }`) unless the run covers all groups (it runs with mode `push`). Steps: `regression = loadRegression(root)`; `run = computeRun({ root, regression, mode: 'push', registerText })` (registerText as in loop-gate-context); with `parsed.writeIds`: rewrite each producing group's ids file and `ids_sha256` from the run's case ids through `saveRegression` (ids are written by the tool, never typed; a group whose ids differ from the saved ones is updated and the change printed via `write`), then return (no record). With `parsed.write` (needs `--increment`, `--decision`, `--reason`; missing -> `{ violations: ['run_needs_increment_decision_reason'] }`): build the record: `schema: 'loop-record-v1'`, `increment`, `round: nextRound(existing record paths, increment)` (list `docs/reports/loop-records` on disk), `decision`, `reason`, `accepted_findings` (the JSON array in `parsed.findings` file, else `[]`), `cases` = `run.cases.map(c => ({ id, status, got_sha }))` with status `pass`/`fail`/`accepted`/`pending` mapped from the scorer class (`MATCH`, `ANSWERED`, `BY-LAW CHANGED`, `NOT SCORABLE`, `DATA` -> pass; `DIFFER`, `NO ANSWER`, `NOT MODELLED`, `OWED` -> fail; a case named in an accepted finding -> accepted), `inputs` = blob ids of every path in `git ls-files` that classifies (`makeClassifier(loadLayer23(root))`) from the index, plus `pins: <scorer pin inputs>` as extra keys `table_version`, `evaluator_version`, `scorer_sha` read from the producer's pin file `inputs`, plus `data:<group>` = sha256 of the group's notices file content for external groups (G68-08); then `bindRecord` and `writeRecordExclusive`. The canary and floors are NOT stored. Prints the written path through `write`. Without `--write` or `--write-ids`: a dry run that prints the case counts and returns no violations.
- `verifyCommand(parsed, write, deps)` (needs `--json`; without it prints a one-line summary): reads all records of the tree, per increment the LATEST record, and prints (through `write`, one JSON document) an array of `{ record, increment, decision, bound_ok, increment_green, canary_ok, red_twins_ok, rounds_since_thresholds, cases: [{ id, status, artifact }] }`: `bound_ok` = `checkBound` with the working tree blobs of the record's own inputs is empty; `increment_green`/`canary_ok` from a fresh push-mode `computeRun` + `incrementGreen` (only for the current increment: others report `null`); `red_twins_ok` = `canary_ok` (the gate's red twin is its canary mutation); `rounds_since_thresholds` from `roundsSinceThresholds`; `artifact` = `mcbylaws/loop/data/ids-<group>.json` of the case's group (look up by the regression set's ids). Derived values are computed here, never read from the record.
- `removeCommand(parsed, write, deps)`: needs `--ruling`, `--group`, `--ids` (comma list); `removeCases(set, group, ids, ruling, rulings)` with the register rulings; violations returned as is; on success `saveRegression` and print what was removed. This is the only door for dropping a regression id.
