## Contract: `evaluateGate(ctx)` -> `{ violations: string[], notes: string[] }` (pure; no I/O)
`ctx` fields (all plain data): `mode` (commit|push|ci); `nameStatus` `[{s,p}]` (staged files at commit, the range union at push/ci); `commits` `[[{s,p}]]` one list per commit (at commit: `[nameStatus]`); `classify` (loop-oracle classifier); `incrementIds`; `rulings` Map; `cardExists`; `latest` `{path, rec}` or null (newest record of the current increment in the checked tree); `newRecords` `[{path, rec}]` (records ADDED in the range); `firstRoundOfIncrement` boolean; `greenHistory` `string[]`; `prereg` object or null; `preregFile` string or null; `preregHistory` (the argument of `checkPreregHistory`) or null; `treeBlobs`; `changedBound` `string[]`; `regression` `{ base, cur }` (either may be null); `floors` `{ percentBase, percentCur, countBase, countCur }` (any null); `baselineOwed` `{line: measured}`; `prevCases` `{ "<id>": {status, got_sha} }`; `newCases` `[{id, introduced_in}]`; `rowsTouched`; `run` or null where `run` = `{ cases: [{id, status, got_sha}], skipped, canary, report: {violations, owed}, counts, baseRows, curRows, regenMismatch: string[], groups, floorsOk }`.
Order of work:
1. `if (!commitStageFires(nameStatus, classify)) return { violations: [], notes: ['out of scope: no code, oracle or generated path changed'] }`.
2. Always: `checkRecordsAddOnly(nameStatus)`, `checkOracleFirst(commits, classify)`, `recordMissing(nameStatus, classify)`. If `record_missing` is among the violations return now (nothing else can be judged).
3. With `rec = latest.rec` (if `latest` is null add `record_missing` and return): `checkRecordShape(rec)`; `checkBound({inputs: rec.inputs, treeBlobs, changedBound})`; `checkDecision(rec, rulings, cardExists)`; `checkOneIncrement({prereg: prereg || {increment: null}, record: rec, rowsTouched, newCases, ids: incrementIds})`; `checkSkipAhead(rec.increment, greenHistory, incrementIds)` only when `firstRoundOfIncrement`; prereg: `checkPreregFile(prereg)`, `checkPreregMoves(prereg, run.baseRows, run.curRows)` when both exist, `preregRefusesAccept(thoseViolations, rec.decision)`, and `checkPreregHistory(preregHistory)` when `mode !== 'commit'` and `preregHistory`; a null `prereg` adds `prereg_missing`.
4. Regression and floors: `checkRegression(regression.base, regression.cur, rulings)` when `regression.cur`; `checkCasesPresent(regression.cur, rec.cases.map(c => c.id))`; `checkFloorEdit` for percent and for count floors when both base and cur exist; `checkOwedRatchet(baselineOwed, run.report.owed)`; `run.report.violations`; `checkCountFloors(floors.countCur, run.counts)` when both exist.
5. The run: when `run` is null, push a note `external groups: not run in CI` if `mode === 'ci'`, and for the other modes add `run_missing`. Else `checkRun({declaredIds: all active ids of regression.cur, cases: run.cases, skipped: run.skipped, canary: run.canary})`; each `run.regenMismatch` item as is (`generated_not_regenerable`); `value_changed_unregistered:<id>` for each record case whose `got_sha` differs from `prevCases[id].got_sha` while its status equals `prevCases[id].status` and no `accepted_findings` entry names that case; the record's case list must equal the recomputed one: a record case whose status or got_sha differs from the run's -> `record_differs_from_run:<id>`.
6. When `rec.decision === 'accept'`: `incrementGreen({increment: rec.increment, ids: incrementIds, groups: run.groups, cases: run.cases.map(with group), floorsOk: run.floorsOk, canaryOk: run.canary.observed === 'fail'})`; each reason -> `accept_but_not_green:<reason>`. (Cases carry their group as `group`.)
Return the de-duplicated violations in first-seen order.
