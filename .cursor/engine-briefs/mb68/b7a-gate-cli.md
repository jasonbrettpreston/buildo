## Contract
- `parseArgs(argv)` (argv without node and script) -> `{ command, mode, root, json, write, writeIds, ruling, group, ids, increment, decision, reason, base, findings, target, error }`. Commands: `check` (the default when `--mode` is given), `run`, `verify`, `regression-remove` (first positional word names it). `--mode=<v>` or `--mode <v>`; `--root=<dir>`; `--json`; `--write`; `--write-ids`; `--ruling=<id>`; `--group=<g>`; `--ids=a,b`; `--increment=<id>`; `--decision=<accept|revert>`; `--reason=<text>`; `--base=<rev>` (push and ci: the base the range starts from; default empty); `--findings=<path>`; `--target=<ref>`. `error` is a string for: no command and no mode; `--mode` not commit/push/ci for `check`; `regression-remove` without `--ruling`, `--group` or `--ids`; any unknown flag (`unknown_flag:<flag>`).
- `exitCodeFor({ violations, error })` -> 2 when `error`, else 1 when violations non-empty, else 0.
- `formatReport({ command, mode, violations, notes })` -> lines: `FAIL <code>` per violation, `note: <text>` per note, then `loop-gate <mode>: ok` or `loop-gate <mode>: <n> failure(s)`.
- Git readers (`root` = repo root, all via `execFileSync('git', ['-C', root, ...])`, stdout text, maxBuffer 64 MB, NO shell, env copy without `GIT_*` variables): `git(root, args)`; `stagedNameStatus(root)` (`git diff --cached --name-status -M --no-renames`... use `--name-status` with `-z` NOT; simple tab form; renames give both paths); `rangeNameStatus(root, base, tip)` (the union over `base..tip`) and `perCommitNameStatus(root, base, tip)` (an array per commit from `git rev-list --reverse --no-merges` then `git show --name-status --format= <sha>`); `mergeBase(root, targetRef)`; `blobIdsAt(root, rev, paths)` -> `{path: blob id}` (rev `':index'` uses `git ls-files -s -- <paths>`, otherwise `git rev-parse <rev>:<path>`, a missing path is simply absent); `readAt(root, rev, path)` (`':index'` -> `git show :<path>`; missing -> null).
- `nameStatusFromText(text)`: pure parse used by the readers (tab separated; `R100\told\tnew` -> two entries with status `R`; empty lines ignored) - export it; the OTHER parser in `loop-oracle.nameStatusOf` may be reused instead: import it and re-export under this name if it already does the job.
- `main(argv, deps = {})` async -> exit code. `deps` lets tests inject `buildContext`, `evaluateGate`, `write` (stdout writer). Default `buildContext` is `import('./loop-gate-context.mjs').buildContext`, `evaluateGate` from `./loop-gate-eval.mjs`, `run/verify/write-ids/regression-remove` are dispatched to `import('./loop-gate-run.mjs')` (`runCommand`, `verifyCommand`, `removeCommand`) — import them LAZILY inside the branch so this module loads without them. Any thrown error is printed as `loop-gate: cannot run: <message>` and returns 2. Entry guard at the bottom: when the file is the process entry (`import.meta.url === pathToFileURL(process.argv[1]).href`) set `process.exitCode = await main(process.argv.slice(2))`.
